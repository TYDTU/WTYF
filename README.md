# Welcome To Your Funeral Podcast

Responsive static landing page for **Welcome To Your Funeral Podcast**.

## Local Preview

Open `index.html` in a browser, or serve the folder with any static server.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` deploys the site to GitHub Pages on every push to `main`.

After the first push, set the repository's Pages source to **GitHub Actions** if GitHub does not do that automatically.
